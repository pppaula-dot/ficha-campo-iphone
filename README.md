# Ficha Campo — iPhone

Versão PWA da Ficha Campo de Acompanhamento, preparada para uso no iPhone sem Mac, Xcode ou assinatura Apple.

- funciona offline após o primeiro carregamento;
- importa arquivos `.ficha` e ZIP de fichas;
- mantém fotos, áudios, GPS, salvamento e exportações;
- foi criada separadamente para não alterar o aplicativo Android.
