## Dados e atualização
- [ ] Abrir uma ficha já existente antes da atualização de teste.
- [ ] Confirmar que textos, observações, fotos e áudios anteriores permanecem.
- [ ] Confirmar que nenhuma ficha é apagada.
- [ ] Fechar e reabrir o app e repetir a conferência.

## Condicionantes
- [ ] Classificação inicia em "Selecione".
- [ ] Opções: Informativa / Executiva.
- [ ] Situação inicia em "Selecione".
- [ ] Opções: Conforme / Não Conforme.
- [ ] "Não Conforme" mostra "Se não conforme, descrever a situação".
- [ ] Trocar para "Conforme" oculta o campo.
- [ ] Voltar para "Não Conforme" recupera o texto antigo.
- [ ] Relatório em "Conforme" não mostra a descrição antiga.
- [ ] Textos importados não mostram ☐ indevido.
- [ ] Checkboxes verdadeiros continuam funcionando.

## Datas e relatórios
- [ ] Datas aparecem como DD/MM/AAAA nos relatórios.
- [ ] Cliente sem foto selecionada gera relatório sem fotos.
- [ ] Cliente com fotos selecionadas inclui somente as marcadas.
- [ ] Relatório interno inclui todas as fotos.

## Fotos
- [ ] Captura pela câmera continua funcionando como antes.
- [ ] Foto mantém orientação correta.
- [ ] Tocar na miniatura abre a foto ampliada.
- [ ] Girar à esquerda funciona.
- [ ] Girar à direita funciona.
- [ ] Rotação mantém vínculo com item/subitem/ponto.
- [ ] Excluir mostra exatamente "Excluir esta foto?".
- [ ] Cancelar não apaga.
- [ ] Excluir remove somente a foto; observação e áudio permanecem.

## Exportação e segurança
- [ ] "Enviar fotos/áudios" gera o acervo.
- [ ] "Enviar ficha completa" inclui dados, 3 relatórios, fotos e áudios.
- [ ] Repetir exportação após fechar/reabrir o app.
- [ ] Confirmar que não ocorre "The database connection is closing".
- [ ] No iPhone, salvar uma cópia do ZIP em Arquivos e conferir o conteúdo.
